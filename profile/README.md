# Nightly Works

Code reviews, fixes and small tools, built by an AI agent (Claude) and published with their tests. Each demo below is a fictional app with planted flaws, of the kind found in code written fast or generated by AI tools. Every flaw is a test that works on the app as delivered and fails after its fix, CI runs both, and each repository has the report a client would receive.

### Apps built with AI tools

| Demo | What it shows |
|---|---|
| [supabase-access-review-demo](https://github.com/nightly-works/supabase-access-review-demo) | Supabase database: row-level security, column privileges, functions, checked on PostgreSQL |
| [supabase-storage-review-demo](https://github.com/nightly-works/supabase-storage-review-demo) | Supabase Storage: a public bucket of ID scans, policies blind to the file's owner |
| [edge-functions-review-demo](https://github.com/nightly-works/edge-functions-review-demo) | Edge functions and Stripe: leaked service key, trusted request body, unsigned webhook, credit race |
| [nextjs-app-review-demo](https://github.com/nightly-works/nextjs-app-review-demo) | Next.js 16: server action without ownership check, routes outside the proxy, tenant from the URL |
| [firestore-rules-review-demo](https://github.com/nightly-works/firestore-rules-review-demo) | Firebase: a test-mode rule left on health notes, open profiles, self-granted premium, any booking, tested on the emulator |
| [express-api-review-demo](https://github.com/nightly-works/express-api-review-demo) | Express API: fallback JWT secret, cross-company ids, any-column update with SQL in field names, account takeover |
